# 我们的小日子 · Our Little Days

> 把普通的日子，过成我们的故事。

为情侣准备的生活记录空间，收藏一起吃的饭、走过的路，以及值得记住的小瞬间。

**情侣日记 · 共享相册 · 回忆日历 · 纪念日 · 愿望清单 · 情侣点餐**

## 🌿 立即体验

**[打开我们的小日子 → https://ourlittle.asia/](https://ourlittle.asia/)**

手机和电脑均可通过浏览器使用，手机还可以添加到主屏幕。

## 一起收藏生活

- **日常记录**：分享文字和照片，留言、点爱心，快捷填入一句悄悄话。
- **回忆日历**：切换月份、查看有记录的日期，点选某天翻看当天的日常与照片，并进入当天点餐。
- **回忆相册**：按月份翻看照片，留住生活里的光。
- **查找回忆**：组合使用关键词、月份和作者筛选，找回想看的那段日常。
- **纪念日**：记下恋爱起点和重要日子，首页提示未来30天内的纪念日。
- **愿望清单**：收藏想一起完成的小事。
- **情侣点餐**：上架喜欢的菜，分别选择早、午、晚餐想吃什么，看看两个人都想吃的菜。
- **个性化小家**：更换头像和首页封面。
- **站内消息**：查看日常、留言、爱心和点餐更新提醒。
- **回忆与工具**：导出回忆；误删的日常和照片可在30天内到回收站恢复。

每对情侣有各自的小家，日常和照片仅同一小家的账号可见。

## ✨ 最近更新 · 2026年10月

新增日历视图，让回忆有一个按日期翻阅的入口：

1. 打开「日常」，点击「按日历查看」。
2. 切换月份，日期上的数字表示符合当前筛选的日常篇数。
3. 点选某天，查看当天日常及照片数量；也可以叠加关键词和作者筛选。
4. 点击「查看这一天的点餐」，接着看看那天的餐桌。
5. 用「查看整月」「回到今天」或「清除筛选」继续浏览。

同时完善了新手引导、纪念日提示、快捷留言、点餐回到今天及导出范围说明。

## 开始你们的故事

1. 打开网站，分别注册自己的账号，妥善保存恢复码。
2. 一人创建小家，设置在一起的日期，也可以稍后设置。
3. 在账号设置中生成邀请链接或二维码，分享给另一半，也可以使用邀请码。
4. 另一半注册或登录后确认加入小家，就可以一起记录。
