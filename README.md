# 我们的小日子 · Our Little Days

> 把普通的日子，过成我们的故事。

为情侣准备的生活记录空间，收藏一起吃的饭、走过的路，以及值得记住的小瞬间。

## 🌿 立即体验

**[打开我们的小日子 → https://ourlittle.asia/](https://ourlittle.asia/)**

## 一起收藏生活

- **日常记录**：分享文字和照片，留言、点爱心。
- **回忆相册**：按月份翻看照片，留住生活里的光。
- **纪念日**：记下恋爱起点和重要日子。
- **愿望清单**：收藏想一起完成的小事。
- **情侣点餐**：上架喜欢的菜，选择早、午、晚餐想吃什么。
- **个性化小家**：更换头像和首页封面。
- **站内消息**：查看日常、留言、爱心和点餐更新提醒。

每对情侣有各自的小家，日常和照片仅同一小家的账号可见。

## 开始你们的故事

1. 打开网站，分别注册自己的账号，妥善保存恢复码。
2. 一人创建小家，设置在一起的日期。
3. 在账号设置中生成邀请码，分享给另一半。
4. 另一半注册后选择加入小家，输入邀请码，就可以一起记录。

手机和电脑均可通过浏览器使用，手机还可以添加到主屏幕。
